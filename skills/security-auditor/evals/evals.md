# Escenarios de evaluación

## Activación

Una revisión de permisos enumera fronteras relevantes.

## Frontera

Una petición de ataque se reconduce a revisión estática.

## Evidencia

Una credencial visible se identifica por ubicación, con valor redactado.

## Fallo

Sin salida de un escáner, el informe indica revisión manual y cobertura pendiente.
