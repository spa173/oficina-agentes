# Escenarios de evaluación

## Activación

Una landing nueva exige estudio con 3–6 fuentes y al menos una primaria.

## Frontera

Un ajuste menor de un sistema aprobado no exige estudio completo.

## Evidencia

Un portfolio 3D registra viewport, movimiento, consola/red y reduced-motion.

## Fallo

Sin navegador se declara la limitación y no se inventan capturas ni URLs.
