# Referencias de branding y landing pages

Pide a `diseno-web` que entregue un estudio antes de definir la estética de una web nueva, un rediseño significativo o una landing. Un encargo concreto sería «Explora referencias para una landing de software de inventario para comercios pequeños, con solicitud de demo como acción principal».

## Ejemplo de estudio

Consultado el 17 de noviembre de 2026 mediante extracción textual. El tamaño de pantalla y el comportamiento visual quedaron pendientes de comprobar en navegador.

| Fuente | Observación | Aplicación posible |
|---|---|---|
| [Linear](https://linear.app/) | La propuesta de producto precede a una muestra de la interfaz. | Presentar el beneficio para el comerciante y mostrar inmediatamente un flujo real de inventario. |
| [Stripe](https://stripe.com/) | El sitio ofrece rutas diferenciadas de inicio y contacto comercial. | Priorizar «Solicitar demo» y dejar una ruta secundaria de bajo compromiso. |
| [Framer Brand](https://www.framer.com/brand) | Distingue archivos de marca, variantes y reglas de aplicación. | Definir variantes, fondos y espacio de protección para la identidad propia. |
| [One Page Love](https://onepagelove.com/inspiration) | La galería clasifica landings por género y estilo. | Encontrar candidatas comparables y abrir sus sitios originales para confirmar lo observado. |
| [W3C WAI](https://www.w3.org/WAI/standards-guidelines/wcag/) | La guía organiza criterios WCAG para desarrollo y evaluación. | Planear comprobaciones de contraste, foco, reflujo y teclado. |

Para este ejemplo, propondría una marca de tono tranquilo y práctico, con una captura anotada del recuento diario como prueba de producto. Mantendría una sola acción destacada y dejaría el movimiento para explicar un cambio de estado. Validaría legibilidad y orden de foco antes de aprobar la dirección. Evitaría reproducir la identidad o apariencia de las marcas consultadas.
